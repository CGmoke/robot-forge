# projects/ —— 机器人工程项目

> 📖 **本目录是公开可见的。** GitHub 没有「某个目录只有我能看」这种设置 ——
> 仓库设为 public，里面的每个文件对所有人都可见。这里放的东西，等于公开发布。

本目录用于存放**可公开的**机器人工程项目（仿真、导航、感知、抓取等），
每个项目一个子目录、自包含、可独立运行。目录规范与接入自检清单见
[`docs/adding-a-project.md`](../docs/adding-a-project.md)。

## 当前有什么

| 项目 | 说明 |

| [`tianyi25/greeting`](tianyi25/greeting/README.md) | 天轶 2.5 迎宾机器人 ROS 2 **实机**工程：6 个包（接口 / 上半身动作 / 底盘导航 / 语音 / 手柄 / 状态机）。纯原创代码，不含厂商模型资产 |

**依赖厂商模型资产（URDF / STL 网格）的工程仍然不放在这里** —— 那类工程在内部独立仓库中维护。

"内部"指的是**工程所在的位置**，不是这个目录被隐藏：它和一个普通目录一样，
任何人都能浏览。原因是这类工程的模型文件版权属厂商、未取得再分发授权，
详见 [`NOTICE`](../NOTICE)。

与具体机器人解耦、可被任意项目复用的算法，则下沉到 [`packages/`](../packages/)。

## 本目录的约定

```
projects/<project-name>/
├── README.md          # 必需：项目入口文档
├── ros2_ws/           # ROS 2 项目：项目自己的工作空间
├── docs/              # 可选：项目专属长文档
└── assets/            # 可选：演示 GIF、架构图
```

- `projects/` 之间**不允许**互相依赖；公共部分下沉到 `packages/`
- 新增项目前**必读** [`docs/adding-a-project.md`](../docs/adding-a-project.md) 的
  **知识产权自检**一节 —— 第三方模型、网格、数据集未获书面授权时不得提交
- 只有原创、或有明确可再分发授权的内容才能放在这里

## 什么内容可以放进来

| 可以 | 不可以 |
| --- | --- |
| 你自己写的代码、launch、配置、文档 | 厂商交付的 URDF / STL / CAD 文件 |
| 自己测量、自己重建的模型 | 从厂商 SDK 里拷出来的模型资源 |
| 许可协议明确允许再分发的第三方内容（并注明来源与许可） | 许可证不明的代码、模型、数据集 |
| 用标准图元（box / cylinder）表达的几何 | 从第三方模型推导出的网格文件 |
